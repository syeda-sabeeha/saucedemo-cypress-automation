# QA Automation Tech Test – Sauce Demo

## Project Overview
This project is an end-to-end automation test created using Cypress for the Sauce Demo website.

The purpose of this project is to automate the user flow of logging in, purchasing a product, and verifying that the order is completed successfully.

Test URL: https://www.saucedemo.com/

---

## Tech Stack
- Cypress
- JavaScript
- Node.js
